Il sito ufficiale della Lega Basket Serie A (www.legabasket.it) è realizzato con Next.js ed espone un’API REST interna JSON sotto la root /api.   Queste API non richiedono autenticazione OAuth complessa, ma seguono le convenzioni di naming della LBA. Nota bene: l'anno stagionale nei parametri dell'API LBA corrisponde al anno di inizio della stagione (ad esempio per la stagione 2026/27 si passa year=2026 o s=2026).   

1. Mappatura degli Endpoint Principali🗓️ Calendario e PartiteCalendario di una giornata (Round):Endpoint:    GET [https://www.legabasket.it/api/championships/get-championships-matches-scores-by-id](https://www.legabasket.it/api/championships/get-championships-matches-scores-by-id)Parametri:   id: ID della partita / giornatainfo=trueNote: Restituisce la lista dei match di una giornata, squadre, orari, palazzetto, dirette TV e punteggi parziali.   Competizioni e Fasi della Stagione:Endpoint:    GET [https://www.legabasket.it/api/championships/get-championships](https://www.legabasket.it/api/championships/get-championships)Parametri: s={START_YEAR} (es. s=2026)   Note: Distingue le varie fasi (Regular Season, Playoff, Coppa Italia, Supercoppa).   Classifica:   Endpoint: GET [https://www.legabasket.it/api/championships/get-standings](https://www.legabasket.it/api/championships/get-standings) (o /get-championship-standings)   Parametri:    cs_id={CHAMPIONSHIP_ID}🏀 Dettaglio Partita (Box Score, Play-by-Play, Tiri)Box Score di un Match (Statistiche Giocatori/Squadra):Endpoint:    GET [https://www.legabasket.it/api/championships/get-championships-matches-scores-by-id](https://www.legabasket.it/api/championships/get-championships-matches-scores-by-id)Parametri:    id={MATCH_ID}Note: Ritorna il tabellino completo (punti, rimbalzi, assist, valutazione/OER, percentuali di tiro, ecc.) per tutti i giocatori della partita.   Play-by-Play (Azioni in tempo reale):Endpoint:    GET [https://www.legabasket.it/api/championships/get-play-by-play-by-match-id](https://www.legabasket.it/api/championships/get-play-by-play-by-match-id)Parametri:    id={MATCH_ID}Note: Restituisce la cronologia azione per azione, inclusi i tempi, il tipo di azione e le coordinate $(x, y)$ sul campo per la Shot Chart.   Mappa dei Tiri (Shot Chart):Endpoint:    GET [https://www.legabasket.it/api/championships/get-shots-by-match-id](https://www.legabasket.it/api/championships/get-shots-by-match-id)Parametri:    id={MATCH_ID}Note: Dati aggregati dei tiri realizzati/tentati suddivisi per zone del campo.   🛡️ Squadre e RosterLista Squadre della Stagione:Endpoint:    GET [https://www.legabasket.it/api/teams/get-teams](https://www.legabasket.it/api/teams/get-teams)Parametri: items=50&year={START_YEAR} (es. items=50&year=2026)   Note: Restituisce la lista dei club con club_id, club_code e loghi.   Roster della Squadra:Endpoint: GET [https://www.legabasket.it/api/teams/get-team-players](https://www.legabasket.it/api/teams/get-team-players) (oppure /get-roster)   Parametri:    id={TEAM_SEASON_ID}Statistiche Totali Giocatori Squadra:Endpoint:    GET [https://www.legabasket.it/api/teams/get-team-players-stats](https://www.legabasket.it/api/teams/get-team-players-stats)Parametri:    cs_id=1&id={TEAM_SEASON_ID}&s={START_YEAR}📊 Statistiche e GiocatoriLeaderboard / Classifiche Statistiche:Endpoint:    GET [https://www.legabasket.it/api/statistics/get-teams-statistics-by-type](https://www.legabasket.it/api/statistics/get-teams-statistics-by-type)Parametri: cs_id=1&type={type}&s={START_YEAR} (es. type=teams_offensive, type=teams_defensive, o per i singoli giocatori).   Scheda Giocatore / Game Log:Endpoint: GET [https://www.legabasket.it/api/players/get-player](https://www.legabasket.it/api/players/get-player) /    /get-game-logParametri:    id={PLAYER_ID}&s={START_YEAR}
